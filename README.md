# Практические задачи на Scala

Здесь собраны программы, решающие задачи:
- Расчет максимальной выгоды (Task1_DigitsProfit)
- Валидация и фильтрация данных (Task2_EvenOddFilter)
- Анализ текста и подсчет частоты слов (Task3_WordCounter)
- Проверка корректности email (Task4_ValidEmail)
- Форматирование строк (Task5_StringReverser)
